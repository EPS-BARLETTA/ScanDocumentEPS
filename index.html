Sauvegarde et confidentialité

Les données restent dans le navigateur de cet appareil (IndexedDB). GitHub n'héberge pas les noms ni les photos des élèves. Une suppression des données du navigateur peut les effacer : effectue régulièrement une sauvegarde.

Application de démonstration : n'utilise pas encore de données nominatives réelles tant que le stockage, l'accès et la politique de conservation n'ont pas été validés par l'établissement.
